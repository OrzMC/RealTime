# Contributing

Read AGENTS.md, architecture docs, development setup, and the relevant task before coding. Keep changes focused and use branches such as `feature/<topic>`, `fix/<topic>`, or `docs/<topic>`. Never commit directly to main.

Use Conventional Commits, e.g. `feat(core): add timezone-aware clock`. Run `./scripts/verify.sh` and list exact commands/results in the PR. A successful compile alone does not prove Paper/Folia runtime compatibility.

PRs must explain scope, task link, architecture impact, tests, exact platform builds tested, configuration/data migration, risks, and follow-up work. Maintainer approval is required for merge and release.
