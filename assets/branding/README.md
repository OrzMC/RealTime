# RealTime Branding Assets

## Project icon

- `icon.svg`: 512 × 512 hand-authored vector artwork; the canonical, editable source asset.
- The artwork is composed of explicit SVG geometry and gradients, not generated by an image-generation model.
- Visual concept: a gold real-world clock above a redstone cube, with redstone signal traces on a dark Minecraft-inspired background.

For platforms that require raster images, export `icon.svg` to PNG at the required dimensions (for example, 128 × 128). Keep the SVG as the source of truth and commit raster exports as separate derived assets when needed.
