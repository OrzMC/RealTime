# Feature Development Workflow

1. Read AGENTS.md and the task.
2. Verify dependencies and readiness.
3. Inspect implementation and tests.
4. Plan non-trivial changes.
5. Implement in an isolated branch/worktree.
6. Add tests and update docs.
7. Run `./scripts/verify.sh`.
8. Review diff and check for secrets.
9. Update task status and open a PR.
10. Report exact evidence and known gaps.
